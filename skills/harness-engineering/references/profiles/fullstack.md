# Fullstack Profile

Use this profile when the repository contains both product UI and application or service logic.

## Biases

- Keep frontend and backend verification visible in the same harness.
- Preserve one shared status board and handoff flow.
- Observability should cover browser evidence and server-side runtime evidence.

## Expected Repo Outputs

- `CLAUDE.md` should list both UI and service commands.
- `docs/architecture.md` should map the seams between UI, API, and persistence.
- `ui-verify` and `release-check` should both be part of the normal workflow.
